# ESP32 网络蜜罐

一个运行在 ESP32 上的小型网络蜜罐：同时开放 6 个常见服务端口，伪造 banner 与页面，记录所有探测行为（来源 IP、端口、载荷、时间）。

> 定位：**防御视角**的教学工具。目的是理解攻击者扫描行为、练习日志分析，而不是诱导或攻击真实用户。

---

## 功能

| 功能 | 说明 |
|---|---|
| 6 个诱饵服务 | FTP(21)、SSH(22)、Telnet(23)、SMB(445)、RDP(3389)、HTTP(8080) |
| 伪造 banner | 常见真实服务版本字符串（如 `220 (vsFTPd 3.0.5)`、`SSH-2.0-OpenSSH_8.9p1`） |
| 探测记录 | 环形缓冲最多 60 条：IP、端口、服务、载荷（最多 40 字节）、时间戳 |
| 假 Apache 页面 | 8080 端口返回 `Apache 2.4.52` 风格的 "It works!" 页面 |
| 深色 Web 面板 | 总探测次数、日志条数、当前连接设备、逆序日志（载荷高亮） |

---

## 硬件

- ESP32 DevKit V1（ESP32-WROOM-32，4MB Flash）
- USB 数据线

## 烧录

```bash
pio run -d . -t upload --upload-port COM3
```

## 使用

1. 上电后连接热点：

   ```
   SSID: ESP32-Honeypot
   密码: 12345678
   ```

2. 浏览器访问 `http://192.168.4.1` 查看面板
3. 访问 `http://192.168.4.1:8080` 查看假 Apache 首页
4. 用手机或电脑逐个访问 `192.168.4.1:22`、`:21`、`:23` 等端口，制造探测日志

---

## 技术要点

- 6 个 `WiFiServer` 并行监听，`available()` 轮询接受连接
- 每个连接读取最多 40 字节载荷（120ms 窗口），回 banner 后 `stop()`
- `HoneyLog` 环形缓冲，`addLog()` 写入时自动覆盖最旧记录
- 页面渲染时逆序展示，载荷中的控制字符转义为 `.`

---

## 安全与法律边界

蜜罐只在自己的局域网内监听、只记录来探测本设备的请求，不采集任何第三方流量。**不要**把它部署到公共网络用于诱骗他人。

---

## 已知限制

- `NetworkServer::available()` 在新版 Arduino-ESP32 中已标记废弃（建议 `accept()`），当前仅产生编译警告
- 日志保存在 RAM，掉电即失（未做 LittleFS 持久化）
- 单次最多记录 60 条探测
